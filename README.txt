Athletik System V12 (Structured, Stable)
======================================

Ziel: Stabiler Kalender + konservativer Coach. Kein Service Worker, keine PWA.
Damit gibt es kein 'Woche leer' durch SW/Cache.

Deploy (GitHub Pages):
1) Repo: athletic-system
2) Dateien in ROOT hochladen (index.html im Root)
3) Settings → Pages → Deploy from branch: main / (root) → Save
4) URL: https://olivervonderlippe-lab.github.io/athletic-system/

Erststart:
- 'Speichern & Starten' → Startdatum (Montag) eingeben (TT.MM.JJJJ)
- 'Letzte Einheit nachtragen' → Log eingeben → Coach plant nächste Woche.

Backup:
- Export JSON nach Woche 1/2 einmal ziehen.
